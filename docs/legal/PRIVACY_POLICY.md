# 캠퍼스런치 개인정보 처리방침

**최종 개정일:** 2026년 6월 1일  
**시행일:** 2026년 6월 1일

캠퍼스런치(이하 「회사」)는 「개인정보 보호법」 등 관련 법령을 준수하며, 이용자의 개인정보를 보호하기 위해 다음과 같이 개인정보 처리방침을 수립·공개합니다.

---

## 1. 수집하는 개인정보 항목

회사는 서비스 제공을 위해 아래와 같은 정보를 수집합니다.

### 1) 회원가입·로그인 시 (필수)

| 항목 | 수집 경로 | 비고 |
|------|-----------|------|
| 이메일 주소 | 이메일 가입, Google·카카오 로그인 | Supabase Auth·`public.users` |
| 회원 고유 ID | 자동 생성 | `auth.users.id` / `public.users.id` |
| 로그인 수단 | 자동 기록 | `provider` (email, google, kakao 등) |
| 닉네임 | 가입·프로필 설정 | `public.users.nickname`, 제보 표시용 |
| 카카오 회원번호 | 카카오 로그인 시 | `kakao_user_id` |
| 프로필 이미지 URL | Google·카카오 제공 시 (선택) | `avatar_url` (외부 URL 참조) |

### 2) 서비스 이용 과정 (필수)

| 항목 | 목적 | 저장 위치 |
|------|------|-----------|
| 혼잡도 제보 내역 | 혼잡도 표시·통계 | `crowd_reports` |
| 제보 시 GPS 좌표 | 매장 인근 제보 검증 | 제보 `metadata` (lat, lng) |
| 제보 시 닉네임 | 제보자 표시 | 제보 `metadata` |
| 스탬프·리워드 적립 기록 | 리워드 운영 | `user_rewards` |
| 기프티콘(쿠폰) 배정·사용 기록 | 쿠폰함·사용 처리 | `gifticons` |
| 즐겨찾기 매장 ID | 북마크 기능 | `auth.users` user_metadata |
| 앱 접속·배너·푸시 반응 | 이용 통계·품질 개선 | `analytics_events` |
| 문의·피드백 | 고객 응대 | `app_feedback` |

### 3) 기기·권한 관련 (선택·필수 구분)

| 항목 | 구분 | 설명 |
|------|------|------|
| 위치 정보(GPS) | **필수** (회원가입 동의) | 지도·길찾기·제보 검증. OS 권한 허용 시에만 수집 |
| 알림 권한 | 선택 | 평일 12:00·18:00 로컬 추천 알림 (기기 내 스케줄) |

> **참고:** 회사는 OS 버전·기기 모델 등을 별도 컬럼으로 저장하지 않습니다. Supabase·OAuth 제공사의 서버 로그에 접속 IP 등이 기록될 수 있습니다.

## 2. 개인정보의 이용 목적

수집한 정보는 다음 목적으로만 이용합니다.

- 회원 식별, 로그인·세션 유지, 계정 관리
- 식당 혼잡도·웨이팅 정보 제공 및 이용자 제보 반영
- 위치 기반 지도·주변 매장·길찾기 기능 제공
- 스탬프·기프티콘(쿠폰) 리워드 운영
- 이용 패턴 분석, 접속·배너·푸시 통계, **서비스 품질 개선 및 신규 기능 개발**
- 허위 제보·부정 이용 방지
- 이용자 문의·피드백 처리
- 법령상 의무 이행

## 4. 제3자 제공 및 처리 위탁

회사는 원칙적으로 이용자 개인정보를 외부에 **판매·임의 제공하지 않습니다.**

다만 서비스 제공을 위해 아래와 같이 **처리 위탁·국외 이전**이 발생할 수 있습니다.

| 수탁·제공처 | 위탁 업무 | 보관·처리 지역 |
|-------------|-----------|----------------|
| **Supabase Inc.** | DB·인증·파일(기프티콘 이미지) 저장 | 미국 등 (클라우드 리전에 따름) |
| **Google LLC** | Google 로그인(OAuth) | 미국 등 |
| **Kakao Corp.** | 카카오 로그인(OAuth), 지도 SDK | 대한민국 |
| **(이메일)** Supabase Auth / SMTP | 가입 인증 메일 발송 | Supabase·메일 서비스 정책에 따름 |

각 제공사의 개인정보 처리는 해당 사업자의 정책을 따릅니다.

> **Firebase:** 앱 종료 상태에서도 피크·커뮤니티 알림을 보내기 위해 **Firebase Cloud Messaging(FCM)** 을 사용합니다. FCM 기기 토큰은 Supabase에 저장되며 로그아웃·탈퇴 시 삭제됩니다. Firebase Analytics는 사용하지 않습니다.
