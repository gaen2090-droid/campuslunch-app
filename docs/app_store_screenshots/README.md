| 폴더 | 크기 | 용도 |
|------|------|------|
| `ipad_2064x2752/` | 2064 × 2752 | 13" iPad Pro (2026 권장) |
| `ipad_2048x2732/` | 2048 × 2732 | 12.9" iPad Pro |
| `ipad_1668x2388/` | 1668 × 2388 | 11" iPad Pro |
| `ipad_1668x2224/` | 1668 × 2224 | 10.5" iPad |
