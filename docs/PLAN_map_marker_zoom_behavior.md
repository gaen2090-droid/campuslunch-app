# 지도 마커 줌 레벨별 동작 정리

`lib/widgets/restaurant_kakao_map.dart` 기준. 카카오 Vector Map SDK의 zoomLevel은
**레벨↑ = 확대, 레벨↓ = 축소** (구글맵 방식, 대략 0~21 범위).

## 두 개의 독립된 화면-공간 겹침 판정 (줌 레벨 임계값 없음)

둘 다 `MarkerOverlap.resolveVisibleIds`(화면 픽셀 거리 기준 그리디 중복 제거)를 쓰지만
반경이 다르고 순서대로 적용된다. 매장 수·밀집도와 무관하게 항상 같은 규칙으로 동작 —
"레벨 N 이상이면 라벨 표시" 같은 하드 임계값은 쓰지 않는다(제보 많은 매장이 몰려있으면
그 규칙 자체가 무의미해지기 때문).

1. **마커 아이콘 겹침 판정** (`_markerIconRadiusPixels = 10`)
   두 마커 중심 간 화면 거리가 20px(반경의 2배) 이내면 겹친 것으로 보고, 우선순위 낮은
   마커는 아예 등록하지 않는다. 마커가 실제로 포개질 만큼 가까울 때만 걸러지도록 작게 잡음.

2. **매장명 라벨 겹침 판정** (`_labelOverlapRadiusPixels = 46`, 1번을 통과해 실제로 그려질
   마커들 중에서만 계산)
   텍스트는 아이콘보다 훨씬 넓은 영역을 차지하므로 더 큰 반경으로 별도 판정한다. 이 반경
   안에 이미 라벨이 배정된 마커가 있으면 그 매장은 텍스트 없이 아이콘만 표시.

우선순위(둘 다 동일 기준): 선택된 매장이 최우선, 그 외에는 `widget.restaurants` 리스트
순서(안정적) — 화면에 매장이 아무리 많아도 "라벨이 겹치지 않는 것들만" 이름이 뜨는 결과가
된다.

## 이번 조정 이력

1. 최초: `_markerIconRadiusPixels = 30` — 실제 아이콘 크기(스탬프 48px, 핀 72px 폭) 대비
   과도하게 커서 안 겹치는 마커도 숨겨짐 (문제: 너무 확대해야 마커가 뜸).
2. `18`로 축소 — 여전히 부족, 사용자 확인 결과 이 비율에서도 마커가 사라지는 사례 존재.
3. `10`으로 재축소 — 마커가 실제로 포개질 때만 겹침 판정.
4. 라벨 표시를 줌 레벨 임계값(`_labelZoomThreshold = 16`, 전체 온/오프) 방식에서
   **라벨 자체의 화면 공간 겹침 판정**으로 전환 — "이 정도 축소 비율에서는 마커는 전부
   보이되 이름은 일부만" 요구사항은 임계값 하나로 표현할 수 없고(제보 많은 매장이 몰리면
   그 기준도 다 겹쳐서 무의미), 텍스트끼리 화면상 안 겹치는 것만 보여주는 방식만이
   매장 수와 무관하게 항상 성립한다.

## 실기기 튜닝 시 조정 지점 (`restaurant_kakao_map.dart`)
- `_markerIconRadiusPixels`: 마커 겹침 판정 반경. 낮출수록 저배율에서도 더 많은 마커가 동시에 보임.
- `_labelOverlapRadiusPixels`: 라벨 겹침 판정 반경. 낮출수록 더 많은 이름이 동시에 뜸(대신
  다닥다닥 붙어 보일 수 있음). 높일수록 성긴 곳만 이름이 뜸.
